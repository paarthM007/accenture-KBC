# businessintelligence.ai — frontend (C2, Phase 3)

Next.js (App Router) + TypeScript + Tailwind v4. Talks to the C2 API in
`../api` — see the root `README.md` for backend setup.

## Setup

```bash
npm install
cp .env.example .env.local   # then set NEXT_PUBLIC_SHOW_SCENARIO_SWITCHER=true for local dev
```

Regenerate API types whenever the backend's models change (the backend must
be running):

```bash
npm run types
```

## Run

Start the backend first (`uvicorn api.main:app` from the project root), then:

```bash
npm run dev
```

Open http://localhost:3000. The scenario switcher (bottom-right, dev-only —
see `.env.local`) jumps directly to any of the four demo states
(healthy/critical/refusal/degraded) without needing a CSV, using static
snapshots in `src/lib/scenario-fixtures/` generated by
`../scripts/dump_scenario_responses.py`. Regenerate those snapshots if the
backend's mock fixtures or models change.

## Build

```bash
npm run build
```

## Deployment

Not deployed yet (deferred by design for this build — see project decisions).
Intended target: Vercel for this app, Railway for the API. Set
`NEXT_PUBLIC_API_BASE_URL` to the deployed API's URL and leave
`NEXT_PUBLIC_SHOW_SCENARIO_SWITCHER` unset/false for any deployed build.
